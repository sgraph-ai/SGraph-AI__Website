# SGraph-AI Website

Source for [https://sgraph.ai](https://sgraph.ai) — the SGraph AI marketing website.

Pure static HTML/CSS/JS with no build step. Deployed to S3 + CloudFront via GitHub Actions.

---

## Stack

- **HTML / CSS / JS** — no bundlers, no framework, no build step
- **Web Components (Shadow DOM)** — `sg-site-header` plus 10 homepage sections
- **IFD versioning** — versioned source folders under `v0/v0.2/v0.2.0/...` are overlaid
  into a single `latest/` union on S3 (v0.2.0 base + any v0.2.1+ patches)
- **17 locales** — 16 real + Klingon (`tlh`). English (en-GB) is the master;
  other locales are pre-rendered from `en-gb/` by `scripts/generate_i18n_pages.py`
- **Hosting** — S3 + CloudFront across 3 environments (dev, main, prod)

---

## Local Development

No build tools, bundlers, or package managers required. Python 3.12 is the only prerequisite.

```bash
bash scripts/website__run-locally.sh
```

The script replicates the CI IFD overlay locally under `.local-server-website/` and
serves it on port 10060:

- Home: `http://localhost:10060/`
- EN-GB: `http://localhost:10060/en-gb/`
- Pricing: `http://localhost:10060/en-gb/pricing/`
- Security: `http://localhost:10060/en-gb/security/`
- Vaults: `http://localhost:10060/en-gb/vaults/`
- How it Works: `http://localhost:10060/en-gb/how-it-works/`

## IFD Versioning

Versioned source folders live under `v0/v0.2/v0.2.0/...` and are deployed as an
**overlay** on top of `latest/` in S3. Each patch version adds or overrides files —
files from previous versions persist unless explicitly removed. Rollback means
re-syncing an earlier release. Cleanup of stale files is a deliberate, manual step
(typically on major version bumps).

This is why both `_common/` at the site root AND `v0/v0.2/v0.2.0/_common/` exist:
the top-level `_common/` is the live marketing-site root; the versioned `_common/`
is the IFD archive replayed into `latest/` by the deploy script.

## Deployment

Deployment is fully automated via `.github/workflows/deploy-website.yml`:

- **Push to `dev`** → deploys to `https://dev.sgraph.ai` (S3 prefix `websites/sgraph-ai/dev/`)
- **Push to `main`** → deploys to `https://main.sgraph.ai` (S3 prefix `websites/sgraph-ai/main/`)
- **Manual dispatch → `production`** → deploys to `https://sgraph.ai` (S3 prefix `websites/sgraph-ai/prod/`)
- **Region:** eu-west-2 (London)
- **No build step** — files are deployed as-is after i18n pre-rendering

### Cache Policy

| File Type        | max-age   | Duration  |
|------------------|-----------|-----------|
| HTML             | 300       | 5 minutes |
| CSS / JS / JSON  | 86400     | 1 day     |
| Images / Fonts   | 604800    | 7 days    |

CloudFront cache is fully invalidated on every deployment.

### Required GitHub Actions Secrets

Configured under **Settings → Secrets and variables → Actions**:

| Secret                   | Purpose                                 |
|--------------------------|-----------------------------------------|
| `AWS_ACCESS_KEY_ID`      | AWS credentials for S3 + CloudFront     |
| `AWS_SECRET_ACCESS_KEY`  | AWS credentials for S3 + CloudFront     |
| `WEBSITE_S3_BUCKET`      | S3 bucket holding static assets         |
| `WEBSITE_CF_DIST`        | CloudFront distribution ID (prod)       |
| `WEBSITE_CF_DIST_MAIN`   | CloudFront distribution ID (main/stage) |

GitHub Environments required: `dev`, `main`, `production`.
