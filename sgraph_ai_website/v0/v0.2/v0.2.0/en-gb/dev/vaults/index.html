Open Vaults

These vaults are exposed with a public read key — published by design so anyone can read the (already-public) content directly from the encrypted store. Each card below is generated live from /core/public-vaults.json, then verified against the vault by resolving its HEAD commit and decrypting in your browser. The server only ever sees ciphertext.

Loading vault registry…

Write keys are never published here. The collaboration vault has no public read key and is not listed. To expose a new vault, add it to core/public-vaults.json and (optionally) commit a _vault-meta.json to the vault root for the richer details.
