Body prose — Inter

sgraph.ai delivers content from encrypted vaults. Each article is a vault object — fetched, decrypted, and rendered entirely in the browser. No server sees the plaintext. The vault client handles key derivation using a base64url AES-256-GCM read key embedded in the page.
